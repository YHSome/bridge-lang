# 桥语言教程（14 章）

每章都能直接跑。建议顺序：**输出 → 变量 → 判断 → 循环 → 函数 → 容器 → 文件 → 对象 → 报错 → 小项目 → 数据库 → 网络 → 调试 → 新标准库**。

```bash
python 桥.py 运行 教程/示例/01_输出.bridge
```

| 章 | 主题 | 你会学到 | 示例 |
| --- | --- | --- | --- |
| 01 | 输出与注释 | `输出（）`、全角括号、`#` 注释 | `示例/01_输出.bridge` |
| 02 | 变量与类型 | 赋值、`转整数/转小数`、f-string | `示例/02_变量.bridge` |
| 03 | 判断 | `如果/否则如果/否则`、比较词（`大于`/`不小于`） | `示例/03_判断.bridge` |
| 04 | 循环 | `对于 … 在 …`、`当 …:`、`重复 N 次`、`中断/下一步` | `示例/04_循环.bridge` |
| 05 | 函数 | `定义`、`返回`、默认参数 | `示例/05_函数.bridge` |
| 06 | 容器 | 列表/字典/字符串方法（`追加/排序/键/取值`） | `示例/06_容器.bridge` |
| 07 | 文件 | `读取/新建文档`、写回、CSV 表格 | `示例/07_文件.bridge` |
| 08 | 对象 | `类`、`定义` 方法、JSON 对象 | `示例/08_对象.bridge` |
| 09 | 报错 | `尝试执行/捕获 … 作为 …`、`抛出 值错误` | `示例/09_报错.bridge` |
| 10 | 小项目 | 菜单 + 存储 + 借还（简化版） | `示例/10_小项目.bridge` |
| 11 | 数据库 | `读取("x.db")`、建表/插入/查询/事务回滚 | `示例/11_数据库.bridge` |
| 12 | 网络 | `取网页/发请求`、状态码/文本/JSON/保存 | `示例/12_网络.bridge` |
| 13 | 调试 | F9 断点、Ctrl+F5 一行一步、变量面板 | `示例/13_调试.bridge` |
| 14 | 新标准库 | `压缩/编码/临时文件` 与 `命令行` | `示例/14_新标准库.bridge` |

## 学完能干什么

- 看懂 `示例/` 和 `金标准/` 里的所有文件；
- 用 `桥编辑器.pyw` 写代码、按 F5 跑、F9 打断点、Ctrl+F5 调试；
- 把 `图书管理系统/` 改成自己的作业/工具。

## 遇到问题

| 症状 | 怎么办 |
| --- | --- |
| 报「名字错误」 | 看报错下面的「提示」，多半是拼错，`python 桥.py 查 那个词` |
| 全角括号不生效 | 确认是 `（ ）` 或 `( )` 都行，但别混用一半 |
| 想查某个词翻成什么 | `python 桥.py 查 长度` |
| 想看翻出来的 Python | `python 桥.py 查看 文件.bridge` |
| 想断点 | 编辑器里 F9，或 `python 桥.py 调试 文件 --断点 3` |
