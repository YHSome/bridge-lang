# 金标准测试（Golden Test）· 手打规则

这里有 10 份 **标准 Python 文件**，它们是「正确答案」。
你在同目录手打 `01_基础输出.bridge`、`02_分支.bridge`…… 我会把转译产物和这些 `.py` 逐行对比。

> **当前进度**：`01/02/04/05/10` 是**手打版**（你写的），`06/07/08/09` 已附**参考版**
> （按"逐行对应"规则生成，可直接对照抄写，也可以改写成你自己的写法）。
> `03` 手打版卡在第 13 行 `当(计数 < 5)时重复执行:`——这是自创句式；改回 `当 计数 < 5:`
> 或 `当 计数 < 5 时:` 就通过。转译器不会为单个句式开后门（那样语法会失去边界）。

## 一、硬规则（不遵守，diff 必红）

| # | 规则 | 说明 |
|---|---|---|
| 1 | **第 1 行起与 `.py` 第 1 行起逐行对应** | 一份 `.py` 有 N 行，你的 `.bridge` 也必须是 N 行；**不需要写任何头文件**（`转译器位置` 那个设计已废弃） |
| 2 | **注释必须一字不改照抄** | `.py` 里 `# ...` 那几行照样写；少一行后面全错位 |
| 3 | **字符串内容不翻译** | `"你好，世界！"` 保持原样，别改成英文 |
| 4 | **不要改标识符** | `名字`、`成绩表` 这类中文名原样保留，不用翻成英文 |
| 5 | f-string 可以用了 | `f"我叫{名字}"`、`f"{求长度(数据)}"` 都认；`{{ }}` 转义和 `:.2f` 格式也保留 |
| 6 | 全角 / 半角随意 | `（），：` 和 `(),:` 都行，`“你好”` 也行 |
| 7 | 中英混写随意 | `c = a + b`、`print(...)` 原样留着都行 |
| 8 | 版本声明可选 | 想锁版本就在第一行写 `桥语言版本("0.1")`，不写也能跑 |

> 每个 Python 关键字都有**多个中文写法**（`if` 认 `如果/若/假如/倘若`），你顺手写哪个都算对。
> 想查一个词怎么映射：`python 桥.py 查 长度`。
> 特殊：`是` 在赋值等「值位置」读作 `True`（`启动 = 是`），在比较位置读作 `is`（`等级 是 空`）。
> 条件句可以在句尾加语气词：`当 计数 < 5 时:`、`如果 到了 的话:`——「时/的话/的时候」会被吃掉，
> 产物和不写一模一样。但**别加谓语**（`当(…)时重复执行:` 这种不认，冒号+缩进已经表达了「然后做」）。
>
> 另外支持一批**句式糖**（整行重写，产物仍是标准 Python）：
> `重复执行（N）次:` / `重复 N 次:` → `for _ in range(N):`；`永久循环:` → `while True:`；
> `对于 每个 x 在 序列:` → `for x in 序列:`；`如果 条件 那么:` → `if 条件:`；
> `捕获 值错误 时:` → `except ValueError:`；`无论如何:` → `finally:`；
> `跳出循环` / `继续下一次循环` → `break` / `continue`；
> `设 X 为 Y` / `将 X 增加 Y` / `一直重复` / `重复执行直到 条件` / `等待 条件 直到` / `如果…就…` / `输出 值`（照 Scratch 中文积木块）。
>
> **关系词**也能写：`大于/小于/不小于/不大于/至少/至多`、`加上/减去/乘以/除以`。
> 完整体验见 `示例/自然化.bridge`，全清单见 `转译器/规则/语法糖.py`。

## 四、我怎么验收

1. 你打完的 `.bridge` → `python 桥.py 编译 金标准/01_基础输出.bridge -o x.py` → 跟 `01_基础输出.py` 逐行 diff（两边行数、注释、空格都应对得上）；
2. `python 桥.py 运行 金标准/01_基础输出.bridge` → 输出必须与 `python 金标准/01_基础输出.py` 完全一致；
3. `python 自检.py` → 会**自动**做上面两件事：只要同名 `.bridge` 存在就比对输出，不存在就只测 `.py` 本身能跑。

## 五、提醒：不能乱加空格的地方

- `如果` 后面要有空格或标点：`如果 分数 >= 90:` ✅ ；`如果分数 >= 90:` 会被当成一个标识符（转译器有前缀回退兜底，但别依赖它）；
- `定义` 和函数名之间要塞空格：`定义 加法(a, b):` ✅；
- 关键字属于「保留字」，别拿它当变量名（比如 `结果 = 如果` 不行）。
