桥语言里，数据库和网页都不是"库函数"，而是**对象**——跟 文档 / JSON / 表格 一个套路。

## 一、数据库（SQLite）

```python
库 = 读取("图书.db")          # 文件不存在就新建；也可以 打开数据库("图书.db")
表 = 库.建表("图书", {
    "书名": "TEXT NOT NULL",
    "作者": "TEXT",
    "册数": "INTEGER DEFAULT 1",
})

表.插入({"书名": "三体", "作者": "刘慈欣", "册数": 3})
表.插入多([{"书名": "活着", "作者": "余华"}, {"书名": "球状闪电", "作者": "刘慈欣"}])

输出（表.行数）
输出（表.查询("作者 = ?", ["刘慈欣"]))     # 参数化，防注入
表.更新({"册数": 5}, "书名 = ?", ["三体"])
表.删除行("册数 < ?", [2])

输出（表.结构())        # PRAGMA table_info
表.建索引(["作者"])
输出（库.表们())

库.提交()
库.关闭()
库.删除自己()            # 连文件一起删
```

- 表对象的方法：`插入 / 插入多 / 更新 / 删除行 / 查询 / 全部 / 结构 / 加列 / 建索引 / 行数`
- 库对象的方法：`表 / 建表 / 表们 / 执行 / 查询 / 提交 / 关闭 / 删除自己`
- 条件里用 `?` 占位、参数走列表——**别用 f-string 拼 SQL**
- `.删除` 是关键字（del），所以删行叫 `删除行`

## 二、网络（HTTP / 本地文件）

```python
响应 = 取网页("https://example.com")
输出（响应.状态码）          # 200
输出（响应.文本[:100]）       # 按响应编码解码
页面 = 响应.保存("./页面.html")

提交 = 发请求("https://example.com/api", {"名字": "爸爸"}, 方法="POST")
输出（提交.JSON）            # 自动 json 解析，且能按字段点：提交.JSON.结果
```

- 响应对象：`.状态码 / .头部 / .内容（bytes）/ .文本 / .JSON / .保存(路径) / .关闭()`
- `发请求` 的 `数据` 传 dict 会自动 JSON 序列化并加 `Content-Type`；
- 底层还能用 `导入 网络` → `网络.获取 / 网络.请求`（urllib）；
- `file://` 也能读（示例就是这么离线跑的）。
