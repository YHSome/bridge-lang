# 9. 可读性：把 Python 的"仪式"换成中文

Python 里有很多**和你要解决的问题无关、但每次必须写**的东西：`with open(...) as f`、
`lambda x: x.score`、`except Exception as e`、`if __name__ == "__main__":`、
`a[1:3]`、`def __init__(self, ...)`。它们的共同点是：**读者要先翻译一遍才看懂在干什么**。

桥语言的处理办法不是"少打字"，而是**换成一个自解释的中文句子**，产物仍然是标准 Python。

## 一、`a = 文档(...)` 这条思路（已有）

```bridge
配置 = 读取("config.json")     # 不用 with、不用 open、不用 close
配置.端口 = 9090               # 直接点字段
配置.保存()                    # 直接落盘
```

同理还有 `表格` / `数据库` / `事务` / `JSON节点` / `响应`。**赋值即完成，看不见协议**。

## 二、第二批：对象与初始化（本次新增）

```bridge
类 学生:
    定义 初始化(自己, 名字, 分数):      # → def __init__(self, 名字, 分数):
        自己.名字 = 名字                # → self.名字 = 名字
        自己.分数 = 分数

    定义 显示(自己):                    # → def __str__(self):
        返回 f"{自己.名字} 考了 {自己.分数} 分"

    定义 表示(自己):                    # → def __repr__(self):（列表里打印也好看）
        返回 自己.显示()
```

| 写法 | 翻成 |
| --- | --- |
| `自己` / `自身` | `self` |
| `定义 初始化(...)` | `def __init__(...)` |
| `定义 显示(...)` | `def __str__(...)` |
| `定义 表示(...)` | `def __repr__(...)` |
| `父类.初始化()` | `父类.__init__()` |

## 三、第一批：入口 / 异常 / 排序 / 切片 / 二进制 / 压缩包（本次新增）

```bridge
如果 是主程序:                 # → if __name__ == '__main__':
    跑主流程()

尝试执行:
    读配置()
捕获 值错误 记作 出错:          # → except ValueError as 出错:
    输出（"配置有问题：", 出错）

排名 = 排队(全班, 按="分数", 大的在前=真)   # → sorted(…, key=…, reverse=True)
前三 = 第几个到第几个(排名, 1, 3)          # → 排名[0:3]（从 1 数起，两头都算）
第一 = 最后一个(倒过来(排名))              # → 排名[::-1][-1]
开头 = 前几个(名单, 3)                     # → 名单[:3]

图 = 读二进制("截图.png")       # 不用 with open(..., "rb")
输出（图.大小, 图.十六进制()[:16]）
图.保存("副本.png")

包 = 打开压缩包("资料.zip")     # 不用 with ZipFile(...) / extractall
输出（包.名单, 包.条目数）
包.解出(到="解压后/")
包.放进("新文件.txt")
输出（包.文本("a.txt", 编码="gbk"))
```

## 四、约定与坑

1. **`第几个到第几个` 从 1 数起**（和 Python 的 0 起相反），两头都算；写 0 直接报错。
   只给一个数就是取单个元素：`第几个到第几个(名单, 2)`。
2. `排队(数据)` 不写 `按` 时等同普通排序；`按` 收字段名（字典 / 对象都认）或函数；
   英文的 `key=` / `reverse=` 照样透传。
3. `自己` 进了内建表，所以**不能再用它当变量名**（`桥.py 检查` 会提醒）。
4. `显示` / `表示` / `初始化` 只在 `定义 …` 这一种句首形式下生效，普通函数名不受影响。
5. `读二进制` 的对象 `字节` 是 bytes、`文本()` 才对字符串；`内容` 这个名字别用在自定义方法上
   （`.内容` 会被方法表翻成 `.items`）。

## 五、自检

`python 自检.py` 里有 `== 可读性（把 Python 的仪式换成中文）==` 九条，其中一条是**硬指标**：

> `示例/可读性示例.bridge` 的**产物**里不许出现 `with`、`lambda`、`[1:]`、`[-1]`。

这条一旦被破坏，说明有人在语言层面把可读性退回去了。
