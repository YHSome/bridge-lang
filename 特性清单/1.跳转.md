桥语言提供类似cpp的goto功能，中文译为“跳转到”

用法：

```

输出（“你好，世界！”）

计数 = 0

标记 标记1

输出（“你好，世界2！”）

计数 += 1

如果 计数 == 0：
    跳转到 标记1

跳转到 标记2

输出（“你好，世界3！”）

标记 标记2

```

这样就会输出一次“你好，世界！”，两次“你好，世界2！”，而不会输出“你好，世界3！”

不一定非要写“跳转到”，写成“跳转”、“goto”同样也是可以接受的（也就是同一个意思）

限制：

跳转只能在同一个程序的同一个类下方运行，不可以跳转到其他类和函数的代码中

如果跳转到一个没有声明的标记，那么就会报错“该标记不存在”

跳转之后保留原有的所有变量（尽管可能会跳转到该变量尚未创建的位置）
