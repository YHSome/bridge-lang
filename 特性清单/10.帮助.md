# 10. 帮助：在任意词后面加个 `?`

像 Minecraft 的指令帮助：**不知道一个词怎么用，就在它后面加个问号问一句。**

```bridge
如果?          # 问关键字 / 句式糖
排队?          # 问内建函数
列表.追加 ?     # 问某个对象上的方法（加空格也行）
名字?          # 问你自己定义的变量：值和类型
打招呼?         # 问你自己定义的函数：签名、说明、在第几行
?              # 什么都不写 → 分类目录
```

三种写法等价：`如果?`、`如果 ？`（全角）、`如果 ?`（带空格）。

## 输出长什么样（无边框，纯缩进）

```text
如果 · 关键字 + 句式糖
  作用  条件成立就执行下面的块（等价 Python 的 if）
  同义  若 / 假如 / 倘若 / 假若
  语法  如果 <条件> 那么:
        如果 <条件>:
        如果 <条件> 就 <一句话>   （单行，不用缩进块）
  例子  如果 分数 大于 90 那么:
            输出（"优秀"）
```

```text
打招呼 · 你定义的东西
  种类  你定义的函数
  签名  打招呼(名字, 语气='好')
  说明  跟人打招呼
  位置  .验证帮助.bridge 第 2 行：定义 打招呼(名字, 语气="好"):
  调用  打招呼(…)    在全局作用域里可用
```

```text
成绩 · 你定义的东西
  种类  变量（全局作用域）
  类型  list
  值    [90, 78, 95]
  长度  3
```

## 回答是怎么来的（三档，保证任何词都有回应）

1. **手写**（`转译器/帮助.py` 的 `手写` 表）：句式糖、高频关键字/内建、运行时对象；
2. **自动**：其余规则词一律拼出「等价 Python 的什么 + 同义写法 + 只在哪生效」，
   数据全部来自 `规则/` 那几张表，**不会和映射脱节**；
3. **动态**：不是规则词，就去**调用者作用域**找同名东西——
   函数给签名+文档串+`.bridge` 行号，变量给类型+值（列表还多给长度）。

找不到还会猜：`如过?` → 「没找到「如过」。是不是想写「如果」？」（编辑距离，只报够近的）。

## 命令行同款

```powershell
python 桥.py 帮助 如果      # 等于 .bridge 里写 如果?
python 桥.py 帮助           # 分类目录
python 桥.py "?"            # 同上
```

## 名字里不能带问号

`?` 是帮助语法，所以**名字里带问号会直接报错**，而且报的是人话：

```text
方言错误：xxx.bridge 转译后仍然编译不过：invalid syntax
  第 3 行：定义 你好?():
  提示：问号是帮助语法（`如果?` / `如果 ？`），名字里不能带 ?。想问某个词，就把它单独写成一行。
```

## 实现的四个要点

1. **排在所有句式糖最前面**：否则 `输出 ?` 会先被「输出 裸值」这条糖抢走，变成 `print(?)`。
2. `词` 只允许「标识符字符 + 点」（`[\w.]*`），所以 `x=1?` 这种不会被误当成帮助。
3. 整行处理有个"没汉字就跳过"的快路径，这里给 `?` / `？` 单独放行——否则纯符号行 `?` 会被漏掉。
4. 中文按**显示宽度**对齐（一个汉字占 2 列），不然 `作用` / `语法` 两栏会错位。

## 已知边界

- **只能整行**：`x = 计算()?` 不支持（糖是整行匹配）；
- 词里不能有空格：`输出 值?` 不会命中；
- 规则词优先：自己定义的变量若与规则词同名（本来也不建议），问的是规则。
