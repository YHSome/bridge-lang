运行与并行的作用是方便bridge文件之间相互调用

```a.bridge

输出（“你好，世界！”）

返回 1

```

```b.bridge

运行(“a.bridge”)

a = 运行(“./a.bridge”)

输出（a）

```

此时运行b.bridge，将会返回两次“你好，世界！”，以及1（a程序的返回值）

并行同理：

```a.bridge

输出（“你好，世界！”）

返回 1

```

```b.bridge

并行(“a.bridge”)

a = 运行(“./a.bridge”)

输出（a）

```

此时运行b.bridge，将会返回两次“你好，世界！”，以及1（a程序的返回值）

运行和并行的区别是，运行需要等待调用的程序运行完毕才会继续往下执行，而并行不会（相当于单独调用一个线程出来跑程序）

但是运行可以接收返回值，而并行则不允许接收返回值（会忽略调用的程序的返回值）
