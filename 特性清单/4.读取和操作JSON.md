在桥语言里，JSON 和文本文件一样，用「读取（）」就能拿到，但拿到的是**可以按字段操作**的对象。

```config.json
{
  "站点名": "黄埔校区自己的 OJ",
  "端口": 8080,
  "开发": true,
  "管理员": ["张三", "李四"],
  "数据库": {"主机": "127.0.0.1", "端口": 5432}
}
```

```main.bridge
配置 = 读取（"./config.json"）

输出（配置.站点名）            # 黄埔校区自己的 OJ
输出（配置["端口"]）           # 8080（两种写法都行）
输出（配置.数据库.主机）        # 127.0.0.1 —— 嵌套对象按字段一层层取
输出（配置.管理员[0]）          # 张三 —— 数组照常用下标

配置.端口 = 9090               # 改字段
配置.数据库.主机 = "localhost"
配置.管理员.追加（"王五"）      # 数组追加
配置.保存（）                   # 写回 config.json（缩进 2，中文不转义）

输出（配置.取（"数据库.主机"））   # 用点号路径取深层值
输出（配置.有（"端口"））         # 有没有这个字段
输出（配置.条目数）              # 顶层有几个字段
输出（配置）                    # 直接打印，就是格式化后的 JSON
```

补充说明：

- 读取的**后缀是 .json** 时自动变成 JSON 对象；后缀是 .txt 还是普通文档对象；
- 字段名里可以有中文，`配置.站点名` 直接当属性用；
- 数字/字符串/布尔/null 和 Python 侧一一对应（`真`/`假`/`空`）；
- 改完必须调用 `.保存（）` 才落盘（避免半路写一半坏文件）；
- 没有的字段会报「JSON 里没有「xxx」这一项」，不会静默返回空。
