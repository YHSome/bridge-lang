在桥语言里，CSV 和 JSON 一样，用「读取（）」就能拿到，但拿到的是**二维表**：

```scores.csv
姓名,分数
张三,90
李四,85
```

```main.bridge
表 = 读取（"./scores.csv"）

输出（表.表头）          # ['姓名', '分数']
输出（表.行数）           # 3（含表头）
输出（表[1]）             # ['张三', '90']
输出（表.列（"分数"））    # ['90', '85']

表.追加行（["王五", "88"]）
表.保存（）                # 写回 scores.csv

新建表 = 新建文档（"./新表.csv", [["学号", "成绩"], ["001", "77"]]）
```

补充说明：

- 后缀是 `.csv` 时自动变成表格；`.json` 是 JSON 对象；其它是文本文档；
- `表.列(名字)` 按表头取一整列，`表.列(0)` 也能按列号取；
- 保存时用 `,` 分隔、UTF-8 无 BOM，Excel 直接能开；
- 表格里的值都是字符串（CSV 本来就没有类型），要算数自己 `转整数/转小数`；
- 和 JSON 一样，改完要 `.保存（）` 才落盘。
