# 图书管理系统（桥语言）

一个能真的用的命令行图书管理系统：添加 / 清单 / 搜索 / 借书 / 还书 / 删除 / 统计 / 借阅清单 / 备份，
数据存 `图书数据.json`（原子写入 + 时间戳备份）。

规则：**每人同时最多借 3 本**；借期 **14 天**；逾期 **0.5 元/天**（还书时结算）。

## 运行

```bash
python 桥.py 运行 图书管理系统/主程序.bridge
```

从任何目录启动都行——库存固定放在 `图书管理系统/图书数据.json`（模块按 `__file__` 自己算的）。

## 结构

| 文件 | 职责 |
| --- | --- |
| `主程序.bridge` | 菜单 + 命令分发；菜单用 `标记` / `跳转到` 做循环（桥语言独有） |
| `图书.bridge` | 业务：新增、搜索、借书、还书、下架、统计；借阅上限/应还日期/逾期罚金都在这儿 |
| `数据.bridge` | 存储：直接用 JSON 对象（`读取("图书数据.json")`），改完 `.保存()` |

## 数据长这样

> 存的是 JSON 对象而不是字符串：`数据库["图书"].追加(...)`、`书["总数"] += 1` 都直接改内存，
> 最后 `数据.保存(数据库)` 一次性落盘（`json.dumps(indent=2, ensure_ascii=False)`）。

```json
{
  "图书": [
    {"编号": 1, "书名": "三体", "作者": "刘慈欣", "总数": 3, "在借": 1}
  ],
  "借阅": [
    {"图书编号": 1, "书名": "三体", "借阅人": "张三", "时间": "2026-11-12 02:09"}
  ]
}
```

```text

作者：刘慈欣
册数（回车默认 1）：3

请选择：4

  在借册数： 1   可借册数： 2
```

## 它顺手证明了什么

- **中文标识符**：`数据库`、`借阅人`、`在借`、`取新编号` 这些名字在 Python 侧原样存在；
- **桥语言独有语法**：菜单用 `标记 菜单` + `跳转到 菜单`，不是 `while True`；
- **文件对象**：`读取(...).内容` / `新建文档(...)`，以及 `读取(路径).内容.去除空白()` 链式调用；
- **跨文件导入**：`导入 数据` / `导入 图书`（三个 `.bridge` 文件互相 `导入`）；
- **中文报错**：借不存在的书、删还有外借的书，都是中文提示（`捕获 值错误 作为 错误`）。

## 注意

- 库是 JSON 明文，适合小规模/教学；要并发多用户请换 SQLite（`实验-oj转桥/程序/数据库模块.bridge` 里有现成写法）；
- `标记/跳转到` 只能写在函数或模块的第一层，菜单就是这么写的；
- 删掉 `图书管理系统/图书数据.json` 就等于清空重来（备份在 `*.bak` 里）。


## 借阅规则（实测）

```text
请选择：4
图书编号：1
借阅人：张三
已借出：《厚书》 给 张三，应还 2026-11-26（借出 2026-11-12 03:43）

# 同一个人借到第 4 本
借不了： 张三 已经借了 3 本（每人最多 3 本），先还再借

# 逾期后还书
已归还：《甲书》 借阅人 张三
  逾期 2507 天，罚金 1253.5 元
```

- 每人上限在 `图书.bridge` 的 `每人上限 = 3`；
- 借期 `默认天数 = 14`，逾期单价 `每天罚金 = 0.5`；
- 借阅清单（菜单 8）会显示每笔的 `应还 / 逾期天数 / 罚金`；
- 统计（菜单 7）多了 `逾期册数` 和 `罚金合计`。
