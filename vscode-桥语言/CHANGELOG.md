# 桥语言 VS Code 扩展 · 更新

## 0.3.1

- **片段从帮助表生成**：49 条（原来手抄 13 条），`排队` / `帮助` / `第几个到第几个` 这些新词也有了模板；
- **修掉句式糖高亮是死规则的问题**：之前那条规则匹配的是 `语法糖.py` 的源码文本（永远命中不了用户代码），
